# nyx.despotak.is

Νύξ. One page, hand-written HTML and CSS. No build step, no framework, no
third-party requests, no analytics.

- `index.html` — the page
- `style.css`  — the whole design
- `CNAME`      — claims the custom domain; GitHub provisions the certificate
- `.nojekyll`  — skip Jekyll entirely; the files are served as written

Published from the default branch of a user site. There is no workflow, no
action, and nothing to run locally beyond opening the file.
